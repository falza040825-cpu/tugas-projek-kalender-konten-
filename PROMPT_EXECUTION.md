# Prompt Eksekusi Awal — Fase 1

Kamu adalah front-end engineer yang mengikuti kontrak `AGENTS.md`. Baca `docs/PRD.md`, `docs/UI_GUIDELINE.md`, dan `docs/IMPLEMENTATION_PLAN.md` terlebih dahulu. Kerjakan **Fase 1 saja: Fondasi front-end**.

## Target
- Siapkan shell aplikasi Vite yang ringan dengan sidebar, topbar, area konten, tokens warna pastel silver/abu/taupe, tipografi, radius, spacing, serta layout responsif.
- Gunakan vanilla JavaScript dan CSS; jangan menambah dependency selain Vite.
- Buat dummy data terpusat dan pola navigasi dasar yang bisa dipakai halaman fase berikutnya.
- Pastikan dashboard awal menjadi default view dan menu lain dapat menunjukkan placeholder yang jelas, bukan fitur palsu.
- Jaga implementasi sesuai SOT, tanpa backend, login nyata, upload nyata, API, atau fitur tambahan.

## Larangan
- Jangan mulai Fase 2 atau mengimplementasikan semua halaman sekaligus.
- Jangan mengubah isi SOT secara diam-diam.
- Jangan menambahkan framework/library baru tanpa approval.
- Jangan mengklaim fungsi yang belum ada.

## Validasi dan output
1. Jalankan build Vite (`npm run build`) bila memungkinkan.
2. Laporkan file yang dibuat/diubah, validasi dan hasil sebenarnya, serta keterbatasan.
3. Tampilkan ringkasan untuk direview pengguna.
4. Akhiri dengan **Menunggu persetujuan Fase 1**. Jangan lanjut ke Fase 2 sampai pengguna memberi persetujuan eksplisit.
